# BIC21203 Lab 4b - JSON and jQuery
## Lab Description
This lab focuses on JSON data handling, retrieving JSON data using JavaScript fetch(), and DOM manipulation using jQuery.

## Question 1 - Create JSON Data
Create a books.json file containing two books with their titles, authors, publication years, and genres.

## Question 2 - Retrieve and Display JSON Data
Use fetch() to retrieve the data from books.json and display the selected book information.

## Question 3 - jQuery DOM Manipulation
Use jQuery to change text, add a CSS class, and handle button click events.
